## Reglas editoriales

- Mantener estos archivos como fuentes históricas, no como páginas públicas.
- Crear las versiones web en `docs/evaluaciones/` cuando se implemente esa sección.
- Actualizar fechas, académico, sección e instrucciones antes de reutilizar una evaluación.
- Eliminar contraseñas o datos de acceso presentes en documentos antiguos.
- Separar la versión del estudiante de la pauta o solución docente.
- No asumir que `es1/pauta-es1-consultas-sql.sql` está lista para publicar: contiene respuestas incompletas y consultas que requieren revisión.
- Generar los PDF finales desde la versión Markdown revisada, no directamente desde el Word original.
