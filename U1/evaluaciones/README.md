# Evaluaciones de U1

Esta carpeta conserva los documentos Word originales utilizados como fuente para preparar versiones Markdown y PDF. Los originales no deben publicarse directamente en GitHub Pages.

## Inventario

| Archivo | Clasificación | Contenido observado |
| --- | --- | --- |
| `es1/es1-consultas-sql.docx` | Evaluación sumativa 1 | Caso de consultas SQL, 30 %, 35 puntos y 6 requerimientos sobre el esquema OEHR. |
| `es1/pauta-es1-consultas-sql.sql` | Pauta preliminar ES1 | Coincide parcialmente con ES1, pero requiere corrección antes de publicarse. |
| `es2/es2-programacion-plsql.docx` | Evaluación sumativa 2 | Caso de programación PL/SQL, 30 %, 50 puntos, modelo de minimarket, triggers, función, procedimientos y secuencia. |
| `es2/recuperativas/es2-programacion-plsql-recuperativa.docx` | Recuperativa ES2 | Versión alternativa de PL/SQL con cambios en triggers, función, procedimientos y secuencia. |

## Reglas editoriales

- Mantener estos archivos como fuentes históricas, no como páginas públicas.
- Crear las versiones web en `docs/evaluaciones/` cuando se implemente esa sección.
- Actualizar fechas, académico, sección e instrucciones antes de reutilizar una evaluación.
- Eliminar contraseñas o datos de acceso presentes en documentos antiguos.
- Separar la versión del estudiante de la pauta o solución docente.
- No asumir que `es1/pauta-es1-consultas-sql.sql` está lista para publicar: contiene respuestas incompletas y consultas que requieren revisión.
- Generar los PDF finales desde la versión Markdown revisada, no directamente desde el Word original.
