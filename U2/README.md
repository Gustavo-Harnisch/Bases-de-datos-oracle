# Unidad 2

## Organización

- `presentaciones/`: presentaciones de las clases 1 a 4 y sus partes 2.
- `codigos/`: guiones SQL utilizados durante las clases (`U2_C1` a `U2_C4`).
- `guias/`: glosario de la unidad en LaTeX y PDF.
- `ejercicios/`: tareas y actividades propuestas.
- `soluciones/`: soluciones de referencia para la actividad U2_C4 y evaluaciones.

Las variantes se conservan separadas porque emplean prefijos y estilos diferentes.
